# Denis Fedoruk — Fullstack Developer

> Personal developer portfolio built with Vue 3, Vite and modern CSS animations.

Портфолио - **Middle Fullstack Developer с backend-фокусом**.

Основной фокус - разработка backend-систем и API на **Node.js / TypeScript / NestJS**, работа с SQL-базами данных, Redis, RabbitMQ, Docker и Linux. Frontend-направление представлено React, Vue и TypeScript.

Сайт объединяет информацию о профессиональном опыте, техническом стеке, специализации и контактах в одном интерактивном интерфейсе.
